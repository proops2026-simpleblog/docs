# DOP-004 — Cloud Infrastructure (AWS + EKS)

**Project:** Blog / CMS Platform · **PIC:** Trung & Dat Pham (co-owned)
**Status:** ACTIVE · **Last audited:** 2026-10-14 (Day 21)

## 1. Objective
Run the Blog/CMS stack on AWS on demand: a cluster that is created, used and fully torn down in one session, with every resource tagged to its owner and nothing left billing afterwards.

## 2. In scope
- AWS training account `868737222758`, region `eu-west-2` (AZs `eu-west-2a`, `eu-west-2b`).
- EKS cluster `blogcms-trung-lab`, Kubernetes 1.31 — eksctl config `proops2026/eks/cluster.yaml`.
- Managed node group `ng-spot`: 1 × `t3.small` **spot**, public subnets, **no NAT gateway**.
- EBS CSI driver + StorageClass `gp2-csi` (`proops2026/eks/storageclass-gp2-csi.yaml`).
- ECR repositories for the 4 service images (DOP-002).
- Lifecycle scripts in `proops2026/eks/` (create / delete cluster and node group).

## 3. Out of scope
- Production VPC (private subnets + NAT), multi-account, multi-region.
- Long-running environments — every cluster is deleted at session end.
- Managed RDS (Postgres runs in-cluster), Route 53 / ACM / public TLS.

## 4. Acceptance criteria

| # | Criterion | Check | Status |
|---|---|---|---|
| AC-1 | Every AWS resource is tagged `Owner` + `Email` (account tag policy denies creation otherwise) | `aws resourcegroupstaggingapi get-resources --tag-filters Key=Owner,Values=trung_lp` | DONE |
| AC-2 | Create cluster → app reachable through the load balancer → delete, in one session | Day 17 run | DONE |
| AC-3 | After teardown there are zero billable leftovers (cluster, nodes, ELB, EBS) | `aws eks list-clusters --region eu-west-2`; `aws ec2 describe-volumes --filters Name=status,Values=available --region eu-west-2` both empty | DONE — Day 17 caught and deleted 2 orphaned EBS volumes |
| AC-4 | Node IAM role has only the 4 managed policies in `cluster.yaml` + `ec2:DescribeAvailabilityZones` | `aws iam list-attached-role-policies --role-name <node-role>` | DONE |
| AC-5 | Cost guard: spot `t3.small`, max 1 node, no NAT | `grep -E 'spot\|maxSize\|gateway' proops2026/eks/cluster.yaml` | DONE |
| AC-6 | No orphaned IAM roles from console experiments | `aws iam get-role --role-name blogcms-trung-lab-node-role` → NoSuchEntity | ACTIVE — role still exists |
| AC-7 | Cluster is reproducible from git, no console clicks | eksctl config + scripts | DONE |

## 5. Tech stack
AWS EKS 1.31 · eksctl · EC2 spot `t3.small` · EBS CSI · ECR · ELB · AWS CLI v2 (from WSL2)
